# Доказательства

- Разделяй наблюдаемый факт, слова респондента, расчёт, предположение и неизвестное.
- Для каждого материала сохраняй дату, источник или локальный путь, метод получения, сегмент, размер выборки и ограничения, где применимо.
- Для расчётов указывай исходные данные, формулу и диапазон неопределённости. Не выдавай прогноз за выручку.
- Вторичные исследования описывают рынок, но не подтверждают спрос на конкретное предложение.
- Интервью раскрывает опыт; заявка показывает интерес; оплата показывает покупку при определённых условиях; повторная покупка проверяет повторный спрос. Ни один сигнал не подтверждает автоматически остальные гипотезы.
- Ищи отказы и опровергающие наблюдения. Учитывай смещение выборки, дружескую поддержку, скидки, ручное сопровождение и возвраты.
- Не выдумывай источники, интервью, цифры и результаты. Синтетические примеры явно обозначай и не учитывай как свидетельства спроса.
- Исходные данные и идентифицирующие сведения храни только в workspace/. Переноси в продукт только необходимое обезличенное содержание.
- Не отправляй сообщения клиентам, не запускай платные эксперименты и не публикуй предложения без соответствующего разрешения пользователя.
