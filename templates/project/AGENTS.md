# Инструкции разработки продукта

Этот файл адаптируется при создании проекта. После адаптации проект не должен требовать родительского VibeMoney.

## Контекст

Перед изменениями прочитай README.md и docs/product.md. Следуй согласованным границам версии и критериям приёмки. Неизвестные требования обозначай явно.

## Разработка

- Выбери стек в пределах задачи и зафиксируй решение в документации.
- Поддерживай в README точные команды установки, запуска и проверок выбранного стека. Пока кода нет, не заявляй работоспособность приложения.
- Сохраняй пользовательские изменения. Перед Git-операциями проверяй корень репозитория.
- Проверяй изменения соразмерно риску. Сообщай, что выполнено, результаты и ограничения.
- Не добавляй секреты, реальные интервью и персональные данные в Git.
- Не публикуй и не развёртывай продукт без соответствующего разрешения. Учитывай разрешения, уже полученные в текущей работе.
- Новые предположения о спросе не представляй подтверждёнными фактами. Записывай открытые вопросы в docs/product.md.

## Особенности продукта

При создании замени этот раздел конкретными ограничениями, правилами стека и проверками. Если они ещё неизвестны, явно запиши это.
